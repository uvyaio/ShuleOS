# SchoolOS Africa

A modern, mobile-first School Management System built for African schools.

**Live at:** https://[your-username].github.io/schoolos-africa

## Modules
- Admissions Management
- Fee Management (M-Pesa ready)
- Attendance Tracking
- Parent Communication

## Stack
- Frontend: Vanilla HTML/CSS/JS (single file, no build step needed)
- Backend: Supabase (PostgreSQL)
- Hosting: GitHub Pages
